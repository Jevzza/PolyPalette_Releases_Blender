# PolyPalette for Blender

Hey all, this is the Blender plugin for PolyPalette. You need the PolyPalette app too, and that lives in [PolyPalette_Releases](https://github.com/Jevzza/PolyPalette_Releases).

## What you need

- Windows 10 or 11
- Blender 4.2 LTS or newer
- The PolyPalette app, with a trial or a licence

## Installing

Most people never touch this repo. Install the PolyPalette app, open the Connection tab, find your Blender and press Install Plugin. PolyPalette fetches the plugin and sets it up for you.

The full steps, and how the trial works, are in the [app's README](https://github.com/Jevzza/PolyPalette_Releases#installing).

## Installing by hand

You only need this if Install Plugin can't do it.

1. Download `PolyPalette_Blender_v<version>.zip` from the [latest release](https://github.com/Jevzza/PolyPalette_Releases_Blender/releases/latest) and unzip it.
2. Open Blender and click the Scripting tab.
3. In the Text Editor press Open and pick `PolyPalette_Blender_Install.py` from the `install` folder.
4. Press Run Script. The first run takes about a minute.
5. Restart Blender.

If the PolyPalette tab isn't in the 3D viewport sidebar (press N to show it), go to Edit > Preferences > Add-ons, search for PolyPalette and tick it on.

To watch what the script's doing, open the console first with Window > Toggle System Console.
